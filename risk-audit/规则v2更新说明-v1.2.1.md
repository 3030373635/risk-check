# 规则v2更新说明

程序及激活规则包已更新为1.2.1，以用户提供的《风控矩阵及三清单审核规则（审核确认稿）v2》及本次三项补充确认为依据。运行时继续采用本地纯代码，不调用大模型。原始Excel材料和用户提供的Word文件保持不变。

## 本次落实的口径

| 规则 | 当前处理方式 |
| --- | --- |
| 第3条 | 保留已确认口径：接受“是否适用”和原因、备注拆列；填写适用无需另补原因，不适用必须说明原因。 |
| 第4条 | 停用矩阵及系统清单中的平台专项检查，清理文档第7条的残留引用。保留停用编号便于追溯。 |
| 第5条 | 扩充部门、岗位和人员占位词检查；岗位名称出现列举分隔符时要求一岗一行，同一岗位允许多人。泛称或简称无法对应实际部门岗位时，按本次确认写入“待核实”意见。 |
| 第8条 | 包含员工报账。按同一主体、业务、矩阵类型及措施编号配对经办与审核记录；人员重合且职责仅责任类型不同，才提示冲突或同名待核实。明确角色仅接受经办、审核、审批，缺失时提示补充。 |
| 第9条 | 按本次确认恢复措施编号存在性、当前载体引用一致性检查。无法可靠对应时说明具体待核实内容，不认定为已确认错误。 |
| 第10条 | 责任表述须含责任对象、至少一项明确责任属性及负、负有、承担责任等表达；允许准确性、一致性等替代使用，不要求同时具备。 |
| 第13条 | 从原第9条迁入删除线原文检查。仅查相同措施编号对应的岗位职责，全部按原文检查，包括单字和短词；不使用载体别名替换删除原文。 |

第1、2、6、7、11、12条的原有算法保持，第7条继续停用。所有意见仍写入表末代码审核意见列，原有人工意见保留。多个问题按规则顺序换行，无问题留空。

第8条职责比较统一空格、换行及全半角，仅将“主体责任”和“审核责任”的责任类型归一，其他动作词、标点和业务内容保留。人员编号和姓名一对一明确时优先核对编号；只有姓名，或多人编号无法明确对应时，重名只能列待核实。

第10条原文使用“等”，因此词表也接受及时性、有效性、合规性等同类责任属性，避免误报“对移交协议签订及时性负有审核责任”等表述。当前词表为：准确性、一致性、真实性、完整性、合法性、合规性、及时性、有效性、合理性、规范性、经济性、必要性、匹配性、唯一性、重复性。词条依据来自规则口径及业务正文，不从人工审核意见提取；没有放宽为任意“某某性”均可通过。

## 验证结果

- 159项测试通过，覆盖岗位拆行、占位词、角色缺失、同职责条件、人员编号与重名、主体和措施隔离、责任属性及配置校验等情况。
- 信通材料10个工作簿、20张业务表、1347条记录完成复跑，文件写入完成，无运行警告。
- 生成1617条意见，按程序分类包括754条问题、863条待核实类事项；数量不代表独立问题数量或准确率，同一问题可能涉及多行。
- 第9条654条意见均为待核实类，其中包含载体表述或对应关系尚未核清的情况，不能全部视为载体填写错误。第5条原来单列的168条核对限制已按用户确认转入审核意见。
- 第13条仍为5条删除原文问题、1条措施编号缺失提示，证据及落点与1.1.1一致。第3条和第12条的证据及落点亦保持一致。
- 替换633个历史人工意见单元格后，机器意见及内部限制完全一致。251份原始材料和用户提供的Word文件哈希未变。
- 更新后的Word共11页，已逐页检查文字、标题、分页和页码，并保留原文件版式及非正文包结构。

本次意见增加主要源于审核范围和口径变化，不能与旧版意见数量直接比较准确率。程序写入完成不代表所有待核实事项已由人工确认。现阶段完整报送范围仍配置为信通公司205H的第一批06—10业务；审核其他单位需先确认其主体简称、应报范围及相关对应字典。
