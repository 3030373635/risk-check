# 审核意见及人工机器对比版 v1.0.3

本轮按用户反馈改写审核意见，并将信通10份表格、20张正式业务表的人工和机器意见并排展示。审核运行过程仍为纯代码。

## 对比列

- 左列“人工审核意见”：保留原表“9.11初审”的意见原文；原来没有人工意见的地方留空。
- 右列“机器审核意见”：使用通俗表述的审核器意见；没有机器意见的地方留空。
- 原有人工意见列直接改为统一标题。没有人工意见列的表页补一个空列，与机器列相邻。公司自己填写的“修改备注”保留为原业务栏目，没有冒充人工审核意见。
- 两列位于表格最后，统一列宽、自动换行。原业务单元格、公式、批注和其他表页保留不变。

## 机器意见写法

直接说明问题和处理要求，保留必要的核实条件。例如：

| 原写法 | 新写法 |
|---|---|
| 岗位职责缺少宽松口径下可识别的责任表达。 | 岗位职责中未写明应承担的责任，请补充类似“对……的准确性、一致性承担……责任”的表述。 |
| 明确引用载体未在当前矩阵载体集合中找到：验收单。 | 需人工核实：职责中提到“验收单”，但本措施的“控制载体”栏未列出。请核实是否漏填或名称不一致。 |
| 责任句的载体对象无法按确定性规则解析。 | 需人工核实：本行职责表述较复杂，程序无法判断所用单据、台账等是否与矩阵一致，请对照本措施的“控制载体”栏核对。 |
| 经办与审核姓名重合，但无人员ID。 | 需人工核实：经办与审核名单出现相同姓名。请核实是否为同一人；如为同一人，请调整分工。 |

实际单元格保留涉及的具体文件名称、人员姓名和审核条款编号。没有把程序无法判断的情况改成确定错误，没有因更换表述而删除原来的审核发现。

## 验证

- 重新调用审核器执行，产生1324条审核发现；与v1.0.2逐条比较，问题标识、位置、判断级别和证据含义一致。仅责任类型列表的显示顺序因配置文件排序发生变化，比较时按无序列表核对。
- 对比版保留272个有人工意见的单元格，884个单元格显示机器意见；同一单元格可以有多条机器意见。
- 逐格检查人工、机器两列的文字与对应来源一致，无意见的格子留空。
- 对10份文件作OOXML检查：两列以外的业务单元格、公式和相关对象内容未改变，未涉及的压缩包部件字节一致。复用已通过验证的XLS转换副本，不把重新保存整本文件当作保真依据。
- 50个测试项通过，包含79个独立审查用例的入口。20张正式业务表的对比区域已生成检查预览，另检查长意见的换行显示。

程序及激活规则包为1.0.3。新规则模板使用`{advice}`输出通俗审核意见，要求使用1.0.3或更新的审核器。1.0.2原规则包和原审核副本保留不变。核实事项、审核范围和解析能力均沿用原来的判断规则。
