# 风控矩阵审核器 Windows 离线 Web 版

本版支持 Windows 10/11 x64。发布包已包含 Python、审核依赖、页面资源、规则、基准和 LibreOffice，目标电脑不需要安装开发环境，运行时也不需要联网。

## 启动

1. 完整解压 `风控矩阵审核器-v2.0.0-Windows-x64.zip`。
2. 双击解压目录中的 `启动审核器.bat`。
3. Windows 会打开终端并运行本机服务，然后用默认浏览器打开审核页面。

终端窗口是程序运行的一部分，请在使用期间保持打开。关闭浏览器不会停止任务。如需返回页面，再次双击 `启动审核器.bat`，已有服务会重新打开页面，不会重复启动。

## 创建审核任务

1. 在“新建任务”中点击“选择目录”。
2. 在 Windows 目录选择器中选择待审核材料。
3. 确认任务名称和输出预览，然后开始审核。

用户只选择输入目录。输出位置固定为解压目录下的 `outputs`，页面不提供其他输出位置选择。每个任务使用独立子目录，不会覆盖旧结果。

## 查看结果

任务详情显示当前阶段、进度、警告和错误。任务完成后，可直接打开该任务的输出目录、统计表或集中复核结果。

## 退出

- 正常退出：点击页面左下角的“退出审核器”。如果仍有任务，程序会先请求安全停止。
- 强制结束：关闭终端窗口。程序会随终端结束并清理 Worker 及 LibreOffice 子进程，当前任务可能不完整。

不要把关闭浏览器标签页当作退出，也不要在运行中删除或移动发布目录。

## 故障排查

- 启动或任务失败时，查看 `data/logs` 中的日志。
- 运行完整性检查失败时，重新完整解压 ZIP，不要修改 `app` 或 `runtime` 中的文件。
- 如果公司安全软件拦截本机回环服务，只需允许审核器访问 `127.0.0.1`；无需开放局域网或公网端口。
