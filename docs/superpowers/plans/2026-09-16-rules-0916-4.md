**Goal:** 同步 0916-4 有效规则，并实现顺序正确零改动、顺序错误才填充合并单元格并排序。

**Architecture:** 由 `measure_numbers` 提供唯一编号键；`output_0916` 先判断顺序，再在需要时完成无损填充和稳定排序；新增规则能力通过注册表和冻结规则包启用；矩阵增强及反馈表按新版格式输出。

**Tech Stack:** Python 3.12、openpyxl、lxml、pytest、OOXML ZIP 部件编辑

**Spec:** `docs/superpowers/specs/2026-09-16-rules-0916-4-design.md`
