# 0916-3规则更新说明

程序及默认激活规则包更新为1.9.1，依据《风控矩阵0916-3.docx》与《风控矩阵-0916-1.docx》有效正文的逐段差异。新版源文档保存在`规则来源/风控矩阵0916-3.docx`，代码读取修订后的有效正文，不把修订删除内容当作现行规则。

本次正文差异集中在第5条的部门、岗位和人员姓名三段。部门与岗位由整格泛称匹配改为关键词包含匹配；人员姓名段只有标点和修订说明变化，继续检查未填写以及“等”“……”“待定”等占位内容。

| 项目 | 1.9.0口径 | 1.9.1口径 |
| --- | --- | --- |
| 部门泛称 | 整格为泛称或全部由泛称组合时提示 | 只要部门名称包含文档列举的泛称关键词即提示 |
| 具体部门例外 | “项目管理部门-建设部”等泛称加具体部门可通过 | 保持不变；具体后缀仍须自身不含泛称关键词 |
| 岗位泛称 | 主要按整格词表匹配 | 按新版完整词表执行包含匹配，包括“人员、用工人员、归口管理人员、会签人员、项目建设人员、项目承担人员、项目需求人员、资产使用保管人员”等 |
| 查勘人员 | 旧词表包含“勘查人员”，无单独例外 | 整格精确填写“查勘人员”时放行；“现场查勘人员”等带前后缀写法不扩大例外 |
| 人员姓名 | 检查空白及“等”“……”“待定”等占位内容 | 业务判断不变 |
| 不相容岗位清单 | 部门与岗位A、B、C沿用第5条具体性口径 | 同步使用新版关键词包含匹配及“查勘人员”精确例外 |

规则能力新增`field_constraints`版本5，精确例外由规则参数配置；1.9.0及更早的冻结规则包不修改。发布脚本为`tools/publish_rules_0916_3.py`，可从1.9.0重新生成1.9.1草稿与发布包。

验证命令：

```bash
python run_audit.py --doctor
python run_audit.py config-validate 审核器/rulepacks/releases/1.9.1
python delivery_test.py
```

本次新增及0916规则专项测试共23项通过；1.9.1规则包校验和启动诊断通过，源文档及公共基准哈希无异常。完整交付测试共1187项，其中1150项通过、36项失败、1项因未安装可选`onnxruntime`跳过。为区分本次变更与既有问题，另从变更前提交导出干净副本执行同一交付测试：共1175项，其中1138项通过、同样36项失败、1项跳过。因此本次增加的12项交付测试均通过，未新增失败；既有36项失败集中在主体识别及依赖历史材料的旧验收路径，不在本次规则同步范围内。
