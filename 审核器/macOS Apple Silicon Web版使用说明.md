# 风控矩阵审核器 macOS Apple Silicon 离线 Web 版

本版支持 Apple Silicon Mac（M1 及后续芯片）。发布包已包含 arm64 Python、审核依赖、页面资源、规则、基准和 LibreOffice.app，运行时不需要联网。

## 启动

1. 完整解压 `风控矩阵审核器-v2.0.0-macOS-arm64.zip`。
2. 双击解压目录中的 `启动审核器.command`。
3. macOS 会打开终端并运行本机服务，然后用默认浏览器打开审核页面。

终端窗口是程序运行的一部分，请在使用期间保持打开。关闭浏览器不会停止任务。如需返回页面，再次双击 `启动审核器.command`。

## Gatekeeper 拦截时的处理

仅当你已确认来源，且确认要运行的就是本项目发布包时，才对该解压目录执行下列命令。下面假设目录位于“下载”：

```bash
cd "$HOME/Downloads"
xattr -dr com.apple.quarantine "风控矩阵审核器-v2.0.0"
chmod +x "风控矩阵审核器-v2.0.0/启动审核器.command"
```

命令只作用于这个已确认来源的具体发布目录，不要把目标替换为用户主目录、“下载”根目录或其他宽泛路径。解除这个目录的隔离标记后，程序仍会完全离线运行。

## 创建审核任务

1. 在“新建任务”中点击“选择目录”。
2. 在 macOS 目录选择器中选择待审核材料。
3. 确认任务名称和输出预览，然后开始审核。

用户只选择输入目录。输出位置固定为解压目录下的 `outputs`，页面不提供其他输出位置选择。

## 查看结果

任务详情显示当前阶段、进度、警告和错误。任务完成后，可直接打开该任务的输出目录、统计表或集中复核结果。

## 退出

- 正常退出：点击页面左下角的“退出审核器”。如果仍有任务，程序会先请求安全停止。
- 强制结束：关闭终端窗口。程序会随终端结束并清理 Worker 及 LibreOffice 子进程，当前任务可能不完整。

## 故障排查

- 启动或任务失败时，查看 `data/logs` 中的日志。
- 如果完整性检查失败，重新完整解压 ZIP，不要修改 `app` 或 `runtime` 中的文件。
- 如果安全软件拦截本机回环服务，只需允许审核器访问 `127.0.0.1`；无需开放局域网或公网端口。
