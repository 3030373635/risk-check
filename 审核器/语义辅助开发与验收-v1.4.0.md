# 语义辅助与解析修正 v1.4.0

本轮采用确定性规则、可追溯词库和本地小型中文 Embedding。以 BAAI/bge-small-zh-v1.5 为首轮模型，CPU 推理，不调用生成式模型或云端接口。第一版不引入 BM25 或重排序模型。

## 修正顺序

1. 适用性拆分为明确适用、明确不适用、当前无业务、模板沿用/修改、未知、来源缺失。先识别文字表达，再按业务含义执行检查；“暂无业务”和“直接引用”不自动转换为“不适用”或“适用”。适用性检查与岗位覆盖复用同一结果。
2. 选列结合实际业务行内容。对重复列，只比较纳入审核的有效行；明确适用值优先于模板修改说明，真正的相反值仍保持冲突。隐藏列沿用已有原则。
3. 单位简称结合已识别文件主体和表内单位信息。错写的其他单位表头只能在归属证据充分且没有相反证据时解释为模板残留；记录原表头、实际主体、依据和涉及列，不改源文件，不建立跨公司的全局别名。
4. Embedding 在同字段类型及限定业务范围内匹配标准表达、别名候选。词库记录关系、适用范围、来源、限制和反例。候选与已验证关系分开；相似度不能覆盖否定、姓名、责任类型、单位、措施编号、载体限定或第13条原文规则。
5. 原文去重、分批编码、磁盘缓存；模型文件固定版本并校验哈希。运行只接受本地模型，缺失时明确标记语义辅助未运行，不能自动下载或视为通过。
6. 针对本轮暴露的“疗休养／疗养”等编号名称差异，检查同主体、业务、变体及相同编号数字部分的原表记录，明确指出名称差异，不再直接认定岗位清单缺失；不据此建立自动关联。

## 验证

- 以 v1.3.0 为原始基线，另设“仅解析和词库修复”作为语义模型的独立对照，避免把解析修复算作模型收益。
- 信通、湘西真实原文按单位及重复句式分组，开发样本与独立验证样本分开；另设否定、角色、岗位层级、不同单位和相近载体等困难反例。
- 记录恢复完成的检查、保留的真实差异、仍未完成的原因、新增意见来源；不以减少展示条数作为唯一指标。
- 验证第13条同编号、所有短字词和最终有效内容保留口径不变；不读取人工意见作为运行时输入。
- 记录模型来源、权重与运行依赖大小、CPU/系统/内存、冷启动、首次编码、缓存命中、峰值内存及禁止网络后的运行结果。
- 8 GB 内存、CPU、无独立显卡是最低验收目标；本机为 Apple M4 Max、128 GiB，不得将本机耗时或限制线程实验宣称为普通 8 GB Windows 笔记本实测。

## 实际验收范围

程序、规则包、本地模型和候选词库输出已实现。完整材料验证覆盖信通10份文件、湘西199份文件；测试说明和最终数量见[修正与验证报告](../outputs/语义辅助验证-v1.4.0/修正与验证报告.md)。

本轮模型分类测试为开发人员编写的14条开发表达、21条验证表达及16组困难反例。它用于发现模型边界，不是由审核人员独立标注的准确率测试。上文计划中的真实语义关系独立留出集，以及8 GB Windows笔记本实机验收，尚未完成。因此本版不开放相似度自动通过，也不宣称达到生产准确率或完成普通笔记本适配验收。
