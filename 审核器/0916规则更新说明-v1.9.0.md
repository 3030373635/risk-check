# 0916审核规则更新说明

程序及激活规则包更新为1.9.0，依据《风控矩阵-0916-1.docx》与原《审核确认稿V1》有效正文的逐段差异。源文档存于`规则来源/风控矩阵-0916-1.docx`，保留修订格式和批注；代码以新增内容为准，排除修订删除的文字。反馈表示例仅用于展示输出形式，不据此恢复已停用的审核项目。

| 项目 | 原实现 | 本次调整 |
| --- | --- | --- |
| 岗位清单排序 | 提示调整顺序 | 审核前在副本实际排序，优先指定基准；无基准按控制点数字、措施数字排序。同一数字编号连续，标题、说明、空行保留原位置 |
| 省公司责任主体核对列 | 未输出 | 矩阵按业务及措施数字匹配基准责任主体，新增“省公司版本责任主体（核对后删除）”，复制原责任主体的删除线、颜色和相关样式 |
| 第2条说明材料 | 已支持DOC、DOCX、PDF及申请标题 | 保持支持，不只凭扩展名认定说明，不核验说明理由 |
| 第5条具体部门岗位 | 泛称词表较短 | 扩展新版列举的部门、岗位泛称；泛称后注明具体部门的允许；一格多岗位提示拆分；允许一岗多人员 |
| 第6条不相容清单 | 存在性及A/B岗位具体性 | 有内容时部门和A/B/C岗位检查同第5条，空表、无、不涉及不因无明细提出问题 |
| 第7条系统规则内容 | 本期不审核 | 保持停用，不用反馈表示例推定系统内容需要删除 |
| 第8条人员分离 | 同措施、同职责、人员重合即可提示 | 再要求部门和完整姓名一致；职责仅主体/审核责任类型不同。编号无法对应时仍允许同主体业务的唯一控制措施全文对应。角色空白提示“请补充明确角色”，其他角色提示“请核实角色” |
| 第9条编号与删除内容 | 编号、适用性检查；独立第13条检查删除内容 | 保留编号与明确适用性检查；删除的措施或载体仍在对应岗位职责中出现时按第9条提示。只用当前材料，不做历史或业务语义判断 |
| 第10条标准句式 | 单独“负主体责任”等可通过 | 要求责任属性及肯定承担责任表述；属性允许准确性、一致性、合规性、完整性、真实性、有效性、及时性及相应形容词；提示统一为“岗位职责请按照国网标准句式编制。” |
| 第11条角色责任对应 | 多种责任类型需核实 | 明确角色与任一肯定责任类型匹配时不再提示混合责任；不匹配只提示对应关系。无明确角色不声称完成一致性验证 |
| 原第12条排序 | 独立章节及检查 | 新正文删除独立检查，预处理改为对岗位清单按控制措施编号实际排序；不再输出排序检查意见。v1.9.0至v1.9.2曾错误保留该意见，v1.9.3已修正 |
| 原第13条删除原文 | 独立规则 | 停用独立规则，检查归并第9条；保留对应不相容岗位职责核对 |
| 原第14条责任主体适用范围 | 限定六类主体，影响覆盖及不相容清单过滤 | 新版删除整条；停用规则并移除它对其他检查的附加限制，以矩阵有效适用性为依据 |
| 第15条岗位重复项 | 未启用 | 同主体、业务、措施编号、职责、部门、岗位名称、完整姓名、角色相同的记录提示“重复项保留一个即可”，不自动删除 |
| 岗位清单未覆盖编号 | 只生成责任覆盖意见 | 矩阵新增“岗位清单未覆盖的控制措施编号”列，按数字对应列出未覆盖的本行编号，同时提示“请核实适用性。” |
| 意见反馈表 | 无该格式输出 | 每次正式审核输出`_risk_audit/意见反馈表.xlsx`，三列为“所属三级单位名称”“单位名称”“具体情况”，按主体、业务归类，同样提示合并，不同事实保留 |

矩阵两列核对内容放在审核意见前，审核意见保持最右侧；重复运行复用核对列、更新程序意见，不叠加列。原业务数据和源文件不修改。排序展开实际明细合并范围，保留富文本并同步人工批注、VML锚点、超链接。最终矩阵核对列阶段再次核验原业务单元格及迁移意见的XML，防止仅通过前置保真检查。

保留原人工意见及其修订格式；复核只剥离准确追加的旧程序意见块。不同来源人工意见按完整行去重，人工说明引用程序提示时保留完整说明。整包无可承载表格等情况仍保存待回填事项，不能标记写回完成。跨有效明细或跨区域合并、共享/数组公式移动无法安全处理时，排序明确报错，禁止输出错误副本。

岗位清单排序后直接使用新顺序继续审核和写回，不将倒序或原记录分散另行写成审核意见。
