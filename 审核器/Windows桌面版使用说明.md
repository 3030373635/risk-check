# 风控矩阵审核器 Windows 桌面版使用说明

## 使用 GitHub Actions 构建

本项目不要求准备 Windows 电脑。将完整项目推送到 GitHub 后：

1. 打开仓库的“Actions”页面。
2. 选择“构建 Windows 桌面版”。
3. 点击“Run workflow”，再次点击绿色的“Run workflow”确认。
4. 等待“Windows x64 便携版”任务完成。
5. 在运行结果页面底部下载 `风控矩阵审核器-v2.0.0-Windows-x64.zip`。

工作流仅支持手动触发，不会在提交代码或创建标签时自动运行。构建使用固定版本的 Python 依赖和 LibreOffice 26.2.6，并在打包前验证 LibreOffice 官方安装包的 SHA-256。下载得到的 ZIP 解压后即可使用，无需安装程序。

## 开始使用

1. 将收到的 ZIP 压缩包完整解压到本地目录。
2. 双击“风控矩阵审核器.exe”。
3. 第一次启动会自动检查 LibreOffice、审核规则和本地模型。检查未通过时，界面会指出缺失文件的具体位置。

> 请不要只复制 EXE。移动到其他电脑或目录时，必须将整个“风控矩阵审核器-v2.0.0”目录一起移动。

## 创建审核任务

1. 打开左侧“新建任务”。
2. 选择待审核材料目录。
3. 程序会自动使用材料目录名作为任务名称，可以自行修改。
4. 默认输出目录为 `outputs/材料目录名-年月日-时分秒`，例如 `outputs/第一批资料0924-20260924-140506`。
5. 点击“创建并开始审核”。

每次审核都是一个独立任务。可以连续创建多个任务，它们会同时运行，无需等待上一个完成。

## 查看进度和结果

“审核任务”列表会显示任务状态和进度。在程序还在统计材料总量时，进度显示“正在扫描”；获得总量后才显示真实百分比。

点击任务的“查看”或“结果”，可查看当前审核主体、业务、文件、运行时间和结果摘要。完成后可以直接打开输出目录、统计表和集中复核目录。

## 最小化到托盘

有任务运行时关闭主窗口，默认选项是“最小化到托盘并继续运行”。双击 Windows 任务栏通知区的程序图标即可恢复窗口。全部任务结束时会显示通知。

## 停止任务

在任务详情中点击“停止任务”。程序会等待当前安全工作单元完成后停止，已产生的结果会保留。如果退出时任务长时间未响应，程序会再次询问是否强制结束，不会静默终止。

## 常见问题

- 提示“运行资源缺失”：重新完整解压 ZIP，确认 `runtime` 目录与 EXE 在同一目录。
- 无法创建任务：确认材料目录存在，输出位置可写，且输出目录不在材料目录内。
- 任务显示“意外中断”：可以使用“重试”以原材料创建一个新任务；原输出不会被覆盖。
- 双击 EXE 没有新窗口：本程序只允许一个主界面，再次双击会激活已打开的窗口，也请检查系统托盘。

## 隐私与网络

程序不联网。审核材料、规则、本地模型和结果都留在当前电脑上，不会上传。
